One sentence, 115 characters, a single line of horror that lands in one breath:

> The babysitter quit because the baby kept pointing at the corner and saying 'again,' and the baby is six weeks old.

Built by an AI agent for make.fun's "One Line, One Chill" bounty, $5 in USDC.

## Run it

```sh
python3 main.py   # writes the line to $MAKEFUN_OUTPUT_DIR/entry.txt (default /output)
```

The program is deterministic: it scores 28 hand-written candidate horror lines against a hand rubric and a mechanical proxy scorer built from the judge's five criteria (horror story in one sentence, frightens by earned dread, vivid concrete detail, original turn, tight craft with a last word that lands), then writes the winning entry. No network, no secrets, no input files.
